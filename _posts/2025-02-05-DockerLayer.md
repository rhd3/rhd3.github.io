# 도커의 이미지 레이어(Layer)

먼저 도커 이미지란 컨테이너를 만들기 위한 완성된 패키지이고(압축파일의 개념) 컨테이너를 생성할 모든 정보가 들어있어 용량이크다.   
그러나 이미지는 한번 만들어지면 이미지의 불변성에 의해 이미지 내부의 정보는 변하지 않는다.   
그래서 작은 변경사항이 생겨도 다시 이미지를 만들고 다운받아야한다. 이는 매우 비효율적이기 떄문에 도커는 layer개념을 도입했다.   

-----

레이어란 기존 이미지에 추가적인 파일이 필요할 때 다시 다운로드 받는 방법이 아닌 해당 파일을 추가하기 위한 개념이다.   
각레이어는 이전 레이어의 변경사항을 가지고있다. 레이어는 읽기전용레이어, 새로운내용을담은 레이어로 구성된다.   

업데이트된 부분만 이미지로생성하고 실행시점에서 기존이미지를 바뀐부분과 조합해서 이미지 크기는 큰변화가 없으며 이는    
깃 레포지토리에서 업되이트된 내용을 pull하는것과 같다.   

------

이미지를 실행하여 도커 컨테이너를 생성할 때도 레이어 방식을 사용한다.   
컨테이너 생성 시, 기존의 읽기 전용 이미지 레이어 위에 읽기/쓰기 전용 레이어(R/W layer) 를 추가한다.    

이미지 레이어를 그대로 불변의 레이어로 사용하면서, 컨테이너가 애플리케이션 실행 중에 생성하는 모든 파일이나 변경사항은 읽기/쓰기 전용 레이어에 저장되므로   
여러 개의 컨테이너를 실행하면서 이미지는 불변성을 유지할 수 있다.
